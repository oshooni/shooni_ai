# SEO 노션 블로그 작성 스킬

## 목적

현재 페이지와 대화에서 사용자가 제공한 내용을 바탕으로, 검색 의도에 맞고 초보자도 이해하기 쉬운 노션 블로그 글을 작성한다. SEO와 검색 상위 노출 가능성을 높이는 구조를 적용하되 순위를 보장한다고 표현하지 않는다.

## 필수 입력

- 글의 주제 또는 핵심 메시지
- 현재 페이지와 대화에 포함된 사실, 경험, 의견
- 명시된 경우 타깃 독자, 핵심 키워드, 글 길이, 게시 채널

정보가 충분하면 추가 질문 없이 작성한다. 핵심 주제나 독자가 불명확해 결과가 크게 달라질 때만 질문 1개로 확인한다.

## 작성 절차

1. 현재 페이지와 대화의 내용을 가장 우선적인 원문으로 삼는다.
2. 독자의 검색 의도를 정보 탐색, 문제 해결, 비교, 구매·신청 중 가장 가까운 유형으로 판단한다.
3. 핵심 키워드 1개와 연관 키워드 3~5개를 정한다. 사용자가 키워드를 지정하면 그대로 우선한다.
4. 제목에 핵심 키워드와 구체적인 효익을 자연스럽게 넣는다.
5. 도입부에서 독자의 문제, 글에서 얻을 결과, 읽어야 할 이유를 짧게 제시한다.
6. 본문을 명확한 H2·H3 구조로 작성한다. 한 문단에는 하나의 메시지만 담는다.
7. 노션 기능을 설명할 때 기능의 의미, 필요한 상황, 실행 순서, 실제 사용 예시를 함께 제공한다.
8. 사용법은 메뉴 경로와 클릭 순서를 번호 목록으로 작성한다. 화면이나 버전에 따라 달라질 수 있는 명칭은 단정하지 않는다.
9. 추상적인 설명마다 예시, 적용 사례, 전후 비교 중 하나를 추가한다. 실제 사례가 없으면 ‘가상 예시’로 명확히 표시한다.
10. 결론에서 핵심 내용을 요약하고 독자가 바로 실행할 다음 행동을 제안한다.
11. 키워드 과다 반복, 장황한 문장, 근거 없는 수치·성과, 중복 설명을 제거한다.

## SEO 원칙

- 제목 앞부분에 핵심 키워드를 자연스럽게 배치한다.
- 첫 100~150자 안에 핵심 키워드와 글의 효익을 포함한다.
- 검색 질문에 대한 직접 답변을 각 섹션 초반에 배치한다.
- 연관 키워드를 억지로 반복하지 않는다.
- 짧은 문단, 목록, 단계, 표를 활용한다.
- 과장형·낚시형 표현을 피한다.
- 필요하면 FAQ 3~5개를 추가한다.
- 최신 정보가 필요한 내용은 출처를 확인하고, 확인하지 못한 사실은 단정하지 않는다.

## 초보자 친화 원칙

- 전문 용어를 처음 사용할 때 한 문장으로 뜻을 설명한다.
- ‘왜 필요한가 → 무엇인가 → 어떻게 하는가 → 예시 → 주의점’ 순서로 설명한다.
- 한 단계에 한 행동만 안내한다.
- 자주 막히는 지점과 실수 방지 팁을 포함한다.
- 설명 없이 ‘간단히’, ‘당연히’, ‘설정하면 된다’라고 쓰지 않는다.

## 노션 설명 규칙

노션 기능이나 방법을 다루는 각 핵심 섹션에 가능한 범위에서 다음 요소를 넣는다.

- **기능:** 무엇을 하는 기능인지
- **활용 상황:** 언제 쓰면 좋은지
- **사용 방법:** 순서대로 따라 할 수 있는 단계
- **예시:** 구체적인 입력과 결과
- **사례:** 실제 경험 또는 ‘가상 사례’로 표시한 적용 장면
- **주의점:** 권한, 요금제, 데이터 구조, 모바일·PC 차이 등 필요한 제약

## 기본 출력 형식

1. **SEO 제목 후보 3개**
2. **추천 제목 1개**
3. **메타 설명**: 120~160자 내외
4. **핵심 키워드·연관 키워드**
5. **블로그 본문**
    - 도입
    - H2·H3 본문
    - 노션 기능 및 단계별 사용법
    - 예시와 사례
    - 실수 방지 팁
    - 결론과 실행 제안
6. **FAQ**: 필요한 경우 3~5개
7. **썸네일 문구 후보 3개**

사용자가 ‘본문만’, 특정 분량, 특정 플랫폼 형식을 요청하면 해당 형식을 우선한다.

## 문체

- 친절하고 신뢰감 있게 작성한다.
- 초보자에게 말하듯 쉬운 한국어를 사용한다.
- 짧은 문장과 능동태를 우선한다.
- 사용자의 경험과 말투가 드러나는 표현은 보존하되 반복과 구어체는 읽기 좋게 정리한다.
- 성과를 과장하거나 검색 상위 노출을 보장하지 않는다.

## 품질 점검

- 현재 페이지와 대화의 핵심 내용이 반영되었는지 확인한다.
- 독자의 검색 질문에 초반부터 답했는지 확인한다.
- 노션 사용법이 실제로 따라 할 수 있을 만큼 구체적인지 확인한다.
- 초보자가 모를 용어를 설명했는지 확인한다.
- 실제 사례와 가상 예시를 구분했는지 확인한다.
- 키워드가 자연스러운지 확인한다.
- 근거 없는 수치, 출처, 기능을 만들지 않았는지 확인한다.
- 중복과 불필요한 문장을 제거한다.
