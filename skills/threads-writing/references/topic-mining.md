# 소재 발굴

"뭘 쓰지"라는 말이 나오면 이 문서를 읽고 후보를 뽑는다.

## 뽑을 때 원칙

**대화에서 이미 나온 얘기만 재조합하지 않는다.** 사용자 입장에서는 새롭지 않아서 임팩트가 없다. 사용자가 생각도 못 한 바깥 재료를 던져야 "아 그거 관련해서 나 이런 경험 있는데"가 나온다.

**한 번에 여러 개, 카테고리별로 던진다.** 하나를 정성껏 제안하는 것보다 열 개를 결별로 늘어놓는 게 훨씬 잘 걸린다. 사용자가 고르는 과정에서 본인 경험이 딸려 나온다.

**최근 것을 확인하고 던진다.** 유행 타는 소재는 검색으로 지금 상태를 확인한다. 반년 지난 화제를 던지면 신뢰가 깎인다.

## 카테고리

### 개인 서사

가장 잘 나가지만 재고가 한정적이라 아껴 쓴다. 연속으로 쓰면 계정 전체가 무거워진다.

- 인생에서 제일 바닥이었던 시기와 그때의 구체적인 하루
- 나를 바꾼 한 사람과 그 사람이 한 말 한마디
- 실패담 — 성공담은 광고로 읽히고 실패담은 이야기로 읽힌다
- 약점 공개 — 10년 차인데 아직 못하는 것
- 가까운 사람의 한마디 시리즈 — 배우자, 부모, 동료의 무심한 정곡

### 실용 인사이트

저장이 붙는 결. 분류 프레임을 하나 만들어주면 특히 잘 퍼진다.

- 흔히 하는 것 중 남는 것과 안 남는 것 구분하기
- 일을 시작하는 순서 공개
- 뽑는 사람 입장에서 실제로 보는 것
- 이 업계에서 아무도 안 알려주는 것

### 대중이 아는 대상 분석

도달은 좁아도 통찰 있는 사람이라는 인상이 남는다.

- 인물 — 저평가되거나 최근 재조명된 사람의 진짜 역할
- 브랜드 — 겉으로 보이는 성공 요인과 실제 구조의 차이
- 콘텐츠 — 흥행작의 설계를 뜯어보기
- 플랫폼 — 왜 이 방식이 지금 먹히는가

고를 때 기준은 두 개다. 대중이 이미 아는가. 흔한 해석을 뒤집을 수 있는가.

### 시의성

지금 아니면 못 쓰는 것. 검색으로 현재 화제를 확인한 뒤 던진다.

### 진행 중인 일

프로젝트를 굴리고 있다면 이게 1순위다. 실제 진행 상황은 다른 어떤 소재보다 강하다.

- 오늘 터진 문제와 대응
- 지금 미정인 것들 목록
- 예상과 달랐던 반응
- 관계자와의 협의에서 알게 된 것

### 완전히 사적인 것

가볍게 쉬어가는 날 카드. 캐릭터를 세우는 데 쓴다.

- 이름의 유래, 루틴, 성격의 모순
- 울었던 날, 화났던 날

## 바깥 재료 창고

사용자 경험을 끌어내기 위한 마중물. 그 자체로 글이 되기보다 "나도 비슷한 게 있는데"를 유발하는 용도.

**우화·실화** — 굴뚝 청소부 둘 중 누가 세수했나, 침몰하는 배에서 짐을 못 버리는 사람들, 병원에서 제일 위험한 시간은 인수인계 시간

**연구·실험** — 5달러로 두 시간 안에 최대한 벌기(1등은 발표 시간을 팔았다), 혼자 낸 아이디어가 회의보다 많았다는 연구

**다른 업계** — 소방관은 들어가기 전에 나갈 길부터 본다, 셰프가 신입한테 감자를 깎게 하는 이유, 부기장이 말을 못 해서 난 항공 사고

**단어·어원** — 이력서의 어원이 달려온 길이라는 것, 다른 언어에는 없는 한국어 표현

**일상 관찰** — 직접 조립한 가구를 더 비싸게 평가하는 현상, 메뉴가 셋일 때 가운데를 고르는 것

## 사용자에게 되묻기

재료를 던진 뒤 이런 질문으로 경험을 끌어낸다. 추상적으로 묻지 말고 장면을 물어야 답이 나온다.

- 그때 제일 자신 없어 하던 사람이 결국 뭘 해냈어?
- 혼자였으면 절대 못 넘겼을 순간이 있었어?
- 예상 못 한 사람이 예상 못 한 걸 해준 적 있어?
- 그 말을 들었을 때 뭐라고 대답했어?
